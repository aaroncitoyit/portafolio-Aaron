# Screenshots

Carpeta dedicada a capturas de pantalla del proyecto, usadas en el [README](../../README.md).

## Convención

Cada captura se toma en un viewport distinto y se guarda con el nombre correspondiente:

| Archivo        | Viewport     | Dispositivo      |
| -------------- | ------------ | ---------------- |
| `desktop.png`  | 1920 × 1080  | Escritorio       |
| `tablet.png`   | 768 × 1024   | Tablet           |
| `mobile.png`   | 390 × 844    | Móvil            |

## Cómo actualizar

1. Ejecutar `npm run dev`.
2. Tomar la captura en cada viewport (DevTools > responsive design).
3. Sobrescribir el archivo correspondiente.
4. Reflejar el cambio en el [CHANGELOG](../../CHANGELOG.md).

> Las capturas se registran al cumplirse la **Fase 5: Lanzamiento** del [ROADMAP](../../ROADMAP.md).
> Hasta entonces esta carpeta estará pendiente de completar.
