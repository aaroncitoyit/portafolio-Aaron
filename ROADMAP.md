# Roadmap

Plan de desarrollo del portafolio. Cada tarea se marca como completada (`[x]`) una vez terminada.

> **Estado actual del proyecto:** Fase 1 — Hero (Sprint 1 completo)

## Objetivo

Crear un portafolio con calidad suficiente para mostrar en entrevistas, que refleje el nivel de un **desarrollador Full Stack profesional**. Limpio, elegante y minimalista — no recargado.

## Buenas prácticas

- Componentes reutilizables.
- Separación entre datos y presentación (`src/data/`).
- Convenciones de nombres.
- Commits semánticos (`feat`, `fix`, `refactor`, etc.).
- Documentación (README, ROADMAP, CHANGELOG).
- Código limpio y fácil de mantener.
